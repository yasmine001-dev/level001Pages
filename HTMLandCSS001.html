أولًا: HTML

العناوين <h1> … <h6>

ستة مستويات: h1 الأكبر وh6 الأصغر. يُستخدم h1 مرة واحدة للعنوان الرئيسي.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>

ينقل النص إلى سطر جديد. وسم فارغ لا يحتاج إلى وسم إغلاق.

الفقرة <p></p>

فقرة نصية تفصلها مسافة تلقائية عمّا قبلها وبعدها.

<p>First paragraph</p>
<p>Second paragraph</p>

Second paragraph

القوائم <ol> <ul> <li>

ol قائمة مرقّمة، وul قائمة نقطية، وli يمثّل كل عنصر داخلها.

<ol>
  <li>HTML</li>
  <li>CSS</li>
</ol>
<ul>
  <li>Apple</li>
  <li>Orange</li>

</ul>

  2. CSS
  • Apple
  • Orange

الصورة <img>

الوسم فارغ بلا إغلاق، وأهم سماته:

srcمسار الصورة.
altنص بديل يظهر إن تعذّر تحميل الصورة، ويقرؤه قارئ الشاشة.
widthعرض الصورة بالبكسل.
heightارتفاع الصورة بالبكسل.
<img src="cat.jpg"
     alt="A cat on a sofa"
     width="150"
     height="100">

الحاوية النصية <span>

حاوية داخل السطر، لا أثر لها وحدها، وتُستخدم لتنسيق جزء من النص بـ CSS.

<p>I love <span class="hl">coding</span></p>

I love coding :)))

العنوان الوصفي <label>

نص يصف حقل الإدخال 

<label>Name:
<input type="text"> </label>

حقل الإدخال <input>

وسم فارغ يتغيّر سلوكه بحسب السمة type.

type="text"حقل لكتابة نص عادي.
type="email"حقل للبريد الإلكتروني، ويتحقق المتصفح من وجود الرمز @.
type="button"زر، ونصه يؤخذ من value.
valueالقيمة الابتدائية للحقل، أو النص الظاهر على الزر.
<input type="text" value="Ahmed">
<input type="email">
<input type="button" value="Send">




الرابط <a></a>

ينشئ رابطًا ينقل المستخدم إلى صفحة أخرى عند النقر عليه. النص بين الوسمين هو ما يظهر للمستخدم.

hrefوجهة الرابط: عنوان موقع، أو اسم ملف داخل المشروع.
<a href="https://www.google.com">Google</a>
Google

ثانيًا: CSS

المحدِّدات tag / .class / #id

الصيغة العامة: selector { property: value; }

p { }محدِّد وسم: يستهدف كل العناصر من هذا النوع.
.red { }محدِّد صنف (class): يستهدف كل عنصر يحمل هذا الصنف، ويمكن تكراره.
#main { }محدِّد معرّف (id): يستهدف عنصرًا واحدًا فقط، ولا يُكرَّر.
p        { font-size: 20px; }
.red     { color: crimson; }
#special { color: green; }

Tag

Class

ID

لون الحروف color

يغيّر لون النص، بالاسم (red) 

p { color: blue; }

Blue text

لون الخلفية background-color

يغيّر لون خلفية العنصر لا لون النص.

p { background-color: #ffd43b; }

Yellow background

سُمك الخط font-weight

القيم: normal عادي، bold غامق، أو أرقام من 100 إلى 900.

.a { font-weight: normal; }
.b { font-weight: bold; }

Normal

Bold

حجم الخط font-size

يحدد حجم الحروف، وأشهر وحداته px، وتُكتب مباشرة بعد الرقم.

.small { font-size: 14px; }
.big   { font-size: 28px; }

14px

28px

أخطاء شائعة وانت بتحل

  • نسيان ; في آخر كل سطر CSS.
  • نسيان إقفال التاج (مثلًا </p>)، مع ملاحظة إن br و img و input مالهمش إقفال.
  • الخلط بين . للـ class و # للـ id.
  • كتابة font-size: 20 من غير px.
  • استخدام color وانت عايز تغير الخلفية (المطلوب background-color).
